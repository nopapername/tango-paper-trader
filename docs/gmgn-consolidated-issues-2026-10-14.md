新版 action host 内的原生 SVG 和金额文本仍占据 flex 空间。模拟按钮保持 36px 是已有设计，问题是位置偏移，不能仅以高度正确判为通过。第一次“Giant 36px 几何通过”只证明高度，第二次发现补充了横向布局缺陷。

未提交样式在本地实际 DOM 复现页中消除了偏移：四种尺寸、8 个按钮左右边界与宿主差值为 0，文字未溢出、中心点命中正确。但尚未对更新后的已安装插件进行 GMGN 在线验收。

### GMGN-06 / 07：空 K 线、历史报价与连续卖出

- Musclecat 地址：`0x42f34c0783068ddebf4f80fa57e6dced747cffff`。实际点击前显示创建 1 秒、MC $3.1K，买入 0.1 BNB 响应约 278ms。
- 详情 Financial Chart iframe 为 0 子元素、0 canvas。面板显示持仓 2310.91 万枚、总买入 0.1 BNB、入场市值 $3100、当前市值 $0；50% 卖出失败，现金仍为 9.8451 BNB，总卖出仍为 0。
- 回归复现发现历史价格与零报价的无效时间 `priceObservedAt: 0` 混用，导致验证失败。当前修改尝试将历史估值标记为模拟报价并排除虚构横线。
- 代码审查发现未知供应量下，`FALLBACK_INITIAL_MARKET_CAP` 仍触发 `StateCoordinator.canonicalizeFallbackOrder()`，把来源改为 `TANGO_FALLBACK`。部分卖出后，下一次报价可能从 `0.0000031` 变为 `0.0000032`。测试必须每次重新解析并经过协调器，不能复用同一报价绕开此路径。
