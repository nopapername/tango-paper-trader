四、环境与自检步骤

- Node.js 22+、Git、Chrome/Chromium。
- 无外部 npm 依赖，无需 npm install 或复制 node_modules。
- 从仓库根目录运行，Windows PowerShell 使用：
  node --version
  npm.cmd test
  npm.cmd run check
  npm.cmd run build
- macOS/Linux 可将 npm.cmd 改为 npm。其他系统的路径候选已提供，但交接时只实测了 Windows + Node22 + Chrome。
- Chrome 找不到时设置 CHROME_PATH 为本机浏览器可执行文件，不要改成旧电脑绝对路径。
- 测试包含隔离的无头 Chrome DOM/CSS 回归，不操作用户日常浏览器账户。
- src 是源码；dist/tango-paper-trader 是生成安装目录。只修改生成目录不能作为修复。
- build 会替换固定 dist 输出目录，不要在其中存私人文件。
- 构建后逐项比对45个运行文件与已发布 ZIP；本次仅文档整理时不应改变运行文件、权限、版本或 ZIP。
- npm run benchmark 为可选性能工具；图表历史对比需显式提供基准文件路径，不是正常测试构建的依赖。

五、必须保留的行为与安全边界

1. 各链账户、余额、持仓、历史、费用和估值隔离；异步回调必须校验当前路由、链和合约，不能串链或污染新页面。
2. 单链快买跟随 GMGN 明确预设；组合页逐卡识别链，使用对应链的 Tango 原生币预设1/2，不跨链套用组合栏金额。留空、零值和未识别身份按现有规则处理，不用旧金额覆盖明确零值。
3. GMGN“买后代币详情”：打开=新标签，跳转=当前标签，不打开=留在当前页。只在模拟成交成功后执行，保留确认及防重复逻辑。
4. 不削弱报价来源、身份/供应量一致性、原生币汇率新鲜度、账户同步或原生按钮防护。备用报价不得覆盖有效GMGN实时价造成虚假盈利。
5. 无K线不应单独阻止卖出；仍需有效、匹配身份的实时报价，不能用过期缓存伪装实时成交。失败后可刷新报价，不自动重复卖出。
6. 详情市值、持仓原生币估值和盈亏复用一致报价口径。保持费用、部分卖出成本分摊、已实现/未实现盈亏口径；不要以页面暂时显示值反写历史成交。
7. 一键回本目标是累计买入本金减此前净卖出回款；已回本时禁用，不是每次都收回整笔本金。
8. 底部框显示当前链、本地日期已实现“今日盈亏”。跨日重新统计，但不重置余额、持仓或日历历史。
9. 保留双快买、卡片持仓原生币估值标签、持仓抽屉、快捷交易面板、缩放/尺寸记忆/恢复默认、历史买卖点、成交连线、PNG/复制/导出和日历日报。
10. 成交连线是历史成交简单复盘，不冒充真实历史K线；时间、价格、市值单位及缺失字段必须准确。
11. 保留音效开关和播放时机、主题/语言/计价、快捷键 Alt+Shift+Y、GMGN/教程/作者入口及现有邀请码行为，不擅自改动外链或宣传承诺。
12. 笔记使用独立本地存储与 closed Shadow DOM，保留4,000字数限制、1 MiB总空间、脏草稿保护、多标签修订/epoch冲突校验。账户重置不清笔记。
13. JSON新备份含笔记，导入含笔记备份替换笔记；导入无笔记的旧备份保留现有笔记。无效备份原子拒绝，不部分改写账户。
14. 数据面板账户/汇率更新不应丢失未保存的设置草稿。美元汇率加载期和真正缺价要区分，不伪造金额。

六、在线回归建议

先只读核对版本、对应链账户和现有持仓，记录测试前基线，再按任务需要补测：
- 单链及组合链：切链入口、卡片身份、金额/单位、双按钮、持仓估值标签、冷启动与详情返回战壕。

最后一轮在线回归实际覆盖BSC/SOL及组合页、持仓抽屉、已有持仓估值/历史点、日报币种、复盘草稿、折叠和预设编辑取消；没有新增交易，没有重新实测六链连续成交、扩展内部面板和扬声器音效。不要把历史验收结果冒充当前环境已完成结果。

七、保护用户数据和工具限制

- 新电脑、外部Chrome、Codex内置浏览器账户彼此独立；Git不会迁移模拟账户或笔记。
- 需要迁移时让用户从正确旧浏览器导出JSON，再明确选择导入；不自动导入、重置、卸载、清仓或卖出原有仓位。
- 小额测试前记录合约和数量，只清理能明确区分的测试仓位；发现用户同时交易时先核实，不能按余额差猜测用户仓位。
- 不将备份、笔记、浏览器资料、私钥、凭据、审计日志或用户截图提交公开仓库。
- Owl内置浏览器可能拦截扩展内部页或新标签。记录明确错误并对照标准Chrome，不绕过安全策略，也不修改正常Chrome功能来迎合工具限制。
- 工具无法操作扩展管理页时，请用户“仅重新加载扩展”，不要反复卸载重装。需加载新脚本后刷新GMGN，旧页面脚本可能失效。
- 对无法检查的功能明确标记未验证，需要手动配合时说明具体步骤及原因，不声称全部通过。
