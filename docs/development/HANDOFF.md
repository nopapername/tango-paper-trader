- 详情面板“代币复盘”为买入余额上方的紧凑绿色图标入口。一个输入框，每链、每合约、浏览器本地日期一份笔记。
- 盈亏日历提供独立“每日复盘”，支持日期/链筛选和编辑；日历日期原来的盈亏日报分享保留。
- 笔记使用独立本地存储、closed Shadow DOM、4,000字符/份和1 MiB独立总空间。保留草稿关闭保护、多标签修订冲突检测和旧备份兼容。账户重置不会清除笔记。
- JSON备份包含笔记；含笔记的新备份导入替换笔记，不含笔记的旧备份导入保留现有笔记。不要自动导入或修改用户数据。
- 0.3.51–0.3.54 包含详情内嵌战壕快买、GMGN买后导航同步、卖出报价失败主动刷新和官网链接身份误判修复。报价失败不会自动重试卖出。

## 新电脑首次验收

1. 确认仓库与分支，阅读 `DEVELOPMENT.md`。
2. Node.js22+、Chrome就绪后运行 `npm test`、`npm run check`、`npm run build`；Windows可用 `npm.cmd`。
3. 确认构建输出文件与已发布ZIP一致；当前目录新增的开发文件不得出现在输出中。
4. 新浏览器加载构建目录后再做只读验收；需要账户数据时由用户从对应旧浏览器备份迁移。
5. 开始新功能前记录实际测试基线和待办，避免只依赖旧聊天上下文。
