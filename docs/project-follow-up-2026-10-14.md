# GMGN 页面适配与未提交改动复查

日期：2026-10-14（Asia/Shanghai）。项目版本：0.3.0。

当前 GMGN DOM 检查确认三类适配缺陷；对原有未提交改动的独立复查又确认四处回归。本次保留有效修复、补充失败回归用例后修复，重建扩展包。历史审计报告继续保留其原始日期和结论。

## 当前页面适配

Codex 内置浏览器读取了 BSC 战壕、Solana 战壕和 BSC 代币详情页。战壕卡片仍具有 `group/a`、TokenItem 和 `.BuyButton-continer` 结构；详情页仍具有 BaseInfoBar、BaseInfoPriceView、InfoItem 和 Financial Chart iframe。

| 问题 | 处理 |
| --- | --- |
| MC 标签由图标属性呈现，正文仅有金额，旧文本扫描返回零 | 优先读取卡片内 `data-icon="MC"` 明确美元字段，保留旧版文本兜底；不以 V/N 或历史缓存代替缺失 MC |
| 同卡两个按钮为 0.5 / 1 BNB，但栏目 input 为 1，旧代码让两按钮同为 1 | 次要按钮按自身原生文本或槽位直接文本取金额；主按钮跟随栏目输入；过滤 Paper 子元素文本 |
| GTA6 Coin 等符号按空格被截断，FOUR CATS 又被 F 前缀过滤 | 地址文本核对通过后读取 TooltipCopy 显式符号与相邻原名，保留长度和非地址限制 |

## 原有改动复查与追加修复

核心状态和后台、内容适配和图表、Popup/Dashboard 和构建分别经过独立只读复查。原 24 项修复没有被撤销。追加确认问题如下：

| 问题 | 处理与回归 |
| --- | --- |
| 卡片 MC 两次买入后，入场线退回最近 BUY 的 MC，而非持仓均价 | 根据完整独立观测成交历史重建数量、成本和平均 MC；与当前持仓核对一致才显示。5000 / 10000 等额买入应为 7500；部分卖出保留均价；缺失来源或混合估值时隐藏该坐标 |
| 旧存储发生时钟回退，修复 openedAt 后与 canonical fallback BUY 来源断开，后续写入失败 | 若已有可信来源与 openedAt 对应，保留 openedAt，提升 updatedAt 恢复时间关系；严格外部导入仍拒绝原始异常。真实 Engine 来源与 Coordinator 其它币买入、部分卖出、报价更新覆盖此边界 |
| Popup 非法本金提交后重置输入 | 使用保留草稿和焦点的局部刷新，显示错误且不写入 |
| 等待选链保存期间再次切链，旧导航打开旧链 GMGN | 捕获选链版本；版本变化取消旧导航，后续新点击使用已保存选择 |
