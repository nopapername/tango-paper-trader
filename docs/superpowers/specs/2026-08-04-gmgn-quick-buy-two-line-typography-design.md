# GMGN 快捷买入按钮两行文字设计

## 目标

在不改变 GMGN 卡片、操作行、按钮槽位几何和模拟交易行为的前提下，让虚拟快捷买入按钮的文字更大、更易读。当前本地化的模拟盘标识与原生币买入金额改为上下两行，并始终位于外层虚拟按钮内。

## 布局

- `.tango-list-quick-buy` 继续完整填充 GMGN 提供的按钮槽位，并作为唯一可点击元素。
- `.tango-quick-buy-content` 继续保持外层按钮的 `100%` 宽高，内部改为纵向 flex，两行整体水平、垂直居中。
- 第一行使用现有本地化标签：中文为“模拟盘”，英文为 `PAPER`。
- 第二行保留闪电 SVG，并显示买入金额与当前链原生币符号，例如 `0.5 BNB`。
- 两行内部节点不接收指针事件，点击始终由外层虚拟按钮处理。

## 四档字号

字号以当前回归夹具中 GMGN 实际拥有的最小外层高度为边界，不反向撑高槽位：

| GMGN 档位 | 第一行 | 第二行 |
| --- | ---: | ---: |
| 小号 | 7px | 10px |
| 大号 | 8px | 11px |
| 超大号 | 8px | 12px |
| 巨型 | 9px | 13px |

第一行保留主题色背景和圆角，但移除会额外占用纵向空间的边框；两行使用零纵向间距。若真实字体渲染在最小高度中出现像素级越界，以浏览器 Range 边界测试为准，仅向下微调行高，不改变 GMGN 外层几何。

## 安全边界

- 不修改快捷买入绑定、行情、数量、余额、持仓或成交逻辑。
- 不修改真实 GMGN 买入按钮的 `visibility: hidden`、`pointer-events: none` 防护。
- 不使用绝对定位、负边距、transform 放大或 `overflow: visible` 绕过槽位边界。
- 不点击真实或虚拟交易按钮进行验证。

## 回归验证

- 真实 Chrome 夹具继续使用“模拟盘 + SVG + 2.5 BNB”的真实 DOM 结构。
- 四档均断言两行位于 wrapper 内、文字 Range 完整可见、没有横向裁切，且上下行不发生视觉重叠。
- wrapper 与外层虚拟按钮保持相同宽高；slot、host、card 和下一张卡片位置保持 GMGN 基线。
- 虚拟按钮保持可点击；真实按钮保持隐藏且不可点击。
- 运行完整测试、静态扩展检查、构建，并核对源码与 `dist/tango-paper-trader` 哈希一致。
