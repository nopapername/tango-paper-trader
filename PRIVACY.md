# Privacy Policy

Tango Paper Trader stores settings, paper balances, positions, and simulated trade history locally in the browser using Chrome extension storage.

The extension does not request wallet access, private keys, seed phrases, email addresses, or payment information. It does not submit blockchain transactions. Core paper-trading data is not uploaded to Tango or sold to third parties.

The extension reads public token information displayed on supported GMGN pages and locally reuses public token quote fields from responses GMGN has already requested. It requests the public SOL/USD reference price from CoinGecko and may use DEX Screener's public token API only when GMGN and the visible page do not provide enough quote data. These public quote lookups contain token contract addresses and do not contain wallet or personal information.

Users can export, import, or permanently reset their local data from the dashboard.
