# Tango Paper Trader 中文上架文案

版本 0.3.57

名称：Tango Paper Trader — Meme模拟交易练习

简短说明：在 GMGN 练习六链 Meme 模拟交易，查看仓位、盈亏、买卖复盘与日报。无需连接钱包。

详细说明：

Tango 是完全免费的 Meme 模拟交易练习工具，独立于 GMGN。使用模拟资金练习入场、加仓、减仓和回本，不签名、不广播真实交易。

支持 Solana、BSC、Ethereum、Base、Robinhood Chain、X Layer，各链独立余额和仓位。可使用战壕模拟快买、详情页交易面板、按比例卖出和回本工具；卡片显示持仓原生币估值，面板显示当前市值及盈亏。

历史记录与详情页提供买卖点复盘；没有完整行情时，成交点虚线连线明确标注为非真实走势。兼容图表可显示虚拟买卖横线。支持盈亏日历、日报 PNG、成交图片、CSV 与全部账户 JSON 备份恢复。界面支持中文和英文、深浅主题。


模拟数据存储在当前浏览器。插件读取 GMGN 公开行情，并可能向 CoinGecko、DEX Screener 查询参考行情。模拟交易不等同真实市场成交，不保证收益。网站改版和行情缺失可能影响兼容性。

详情交易面板在持仓数量旁显示对应的原生币估值（如 SOL、BNB），报价不可用时显示占位；该显示不改变成交计算。

底部“今日盈亏”仅统计当前链在浏览器本地日期内卖出后的已实现净盈亏，跨天自动从新一天开始统计；不含未平仓浮盈浮亏，不重置余额、持仓或盈亏日历历史。

底部盈亏框和详情交易面板支持拖动边框、四角等比例缩放（75%–150%），字号和按钮同步调整，分别记住尺寸，点击“↺”恢复默认大小。缩放不改变交易、报价、盈亏计算、余额或持仓。

单链时，主快买跟随 GMGN 对应列的明确金额，2 号按钮跟随 GMGN 当前原生预设；留空保留正数模拟兜底，明确为 0 或无效值时禁用。组合链时，两按钮分别使用卡片所属链的 Tango 第 1、2 个原生币买入预设，不换算 GMGN 组合栏金额。

扩展弹窗提供插件详细使用教程，并在隐私入口旁显示作者 @oooooyoung 的 X 主页链接；仅在点击后打开外部页面。


代币复盘：在详情交易面板的买入余额上方点击带笔记图标的“代币复盘”，用一个输入框记录买前想法、认错提醒或交易总结。每条链、每个合约、浏览器本地日期各保存一份；未交易和已清仓代币也可记录。盈亏日历中的“每日复盘”按日期及链回看和编辑。笔记只在当前浏览器本地保存，不自动上传；每份最多4,000字符，独立空间1 MiB。JSON备份包含笔记；导入不含笔记的旧备份会保留现有笔记。

详情页内嵌战壕同样支持模拟快买。战壕模拟买入后可跟随已读取的GMGN“买后代币详情”设置：新标签打开、当前页跳转或不打开；单链及组合页首次使用时请打开一次GMGN自定义弹窗同步该选择，未读取时保留不打开行为。
